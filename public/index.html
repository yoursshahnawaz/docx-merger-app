Merge Word Documents

A JavaScript library that combines multiple .docx files into one, faithfully preserving styles, tables, images, and numbering.

What gets preserved

Everything you'd expect to survive

docx-merger goes beyond simple concatenation — rich document elements are correctly merged and remapped.

Styles & Fonts

Headings, paragraph styles, fonts, and colors transfer cleanly from every source document.

Images

Embedded images are extracted, remapped, and correctly re-embedded in the output document.

Tables

Complex multi-column tables with borders, shading, and merged cells survive the merge intact.

Bullets & Numbering

List styles, numbering schemes, and indent levels are remapped so lists continue correctly.

    Get Started

    One install away

    Drop it into any Node.js project. Works with callbacks or promises, and has a browser build too.

    npm install docx-merger
    View full docs on GitHub 
    // Node.js usage
const DocxMerger = require('docx-merger');
const fs = require('fs');

const files = ['doc1.docx', 'doc2.docx']
  .map(f => fs.readFileSync(f, 'binary'));

const docx = new DocxMerger({}, files);

docx.save('nodebuffer', (data) => {
  fs.writeFileSync('merged.docx', data);
});
